# 🎭 EmotionSense

**EmotionSense** is an AI-powered web application that detects and displays human emotions in real time using facial expressions.  
It uses **face-api.js** to analyze live webcam input and shows corresponding emotions with dynamic visuals, emojis, and messages — creating an interactive and empathetic user experience.

---

## 🚀 Features

- 🎥 **Live Emotion Detection** — Detects happiness, sadness, anger, surprise, and neutral expressions in real time.  
- 🎨 **Dynamic UI** — Background and emoji change smoothly based on detected emotion.  
- 🧠 **AI-Powered** — Uses `face-api.js` for face and emotion recognition directly in the browser.  
- 🔒 **Privacy-Friendly** — No data storage or uploads; everything runs locally.  
- 💡 **Beautiful Design** — Clean, glassmorphism-inspired interface with subtle animations.

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **AI Library:** [face-api.js](https://github.com/justadudewhohacks/face-api.js)  
- **Framework:** Pure Web (no backend required)
